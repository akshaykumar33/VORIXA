# Accessibility Skill

Use this skill when auditing or implementing UI accessibility features.

## Guidelines
1. **Remappable Controls**: Never hardcode physical key inputs without action bus binding.
2. **Motion Sickness Toggles**: Support turning off camera roll, head bobbing, and rapid FOV changes.
3. **Audio Cues**: Accompany visual reticle markers with directional spatial audio cues.
