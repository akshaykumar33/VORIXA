# Documentation Skill

Use this skill when updating systems, changing public APIs, or recording architectural decisions.

## Guidelines
1. **Documentation Tracks Code**: Every code change must update corresponding architecture docs and roadmaps.
2. **ADR Mandate**: Major dependency additions or architectural paradigm shifts require an accepted ADR.
3. **Evidence-Based Claims**: Never describe an unfinished system as complete or production-ready.
