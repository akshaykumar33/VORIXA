# Release Management Skill

Use this skill when preparing releases, tagging milestones, or deploying production builds.

## Guidelines
1. **Semantic Versioning**: Increment `MAJOR`, `MINOR`, or `PATCH` according to SemVer 2.0.0.
2. **Changelog**: Update `CHANGELOG.md` with categorized bullet points (Added, Changed, Deprecated, Removed, Fixed, Security).
3. **Artifact Verification**: Verify production build assets execute without errors.
