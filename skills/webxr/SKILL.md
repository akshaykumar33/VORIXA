# WebXR Development Skill

Use this skill when developing VR/AR viewports, stereo projection matrices, or spatial controllers.

## Guidelines
1. **Target 90 FPS**: WebXR viewports require $90\text{Hz}$ / $11.1\text{ms}$ frame budgets to prevent cyber-sickness.
2. **Action Bus Adapter**: Map WebXR controller inputs directly to the Normalized Action Bus.
3. **Comfort Locomotion**: Provide vignette tunneling on rapid turning.
