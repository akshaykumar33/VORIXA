# Phase 07: Natural Input & WebXR

* **Status**: Research / Experimental
* **Prerequisites**: Phase 03 Procedural World + Phase 02 Combat

## Objectives
Extend VORIXA into an immersive virtual/augmented reality spatial experience using standard WebXR device APIs.

## Key Deliverables
1. **WebXR Session Pipeline**: Stereo viewport render targets with dynamic foveated rendering.
2. **6DoF Controller & Hand Tracking**: Adapting spatial hand gestures to the Normalized Action Bus.
3. **Comfort Locomotion**: Vignette tunneling options, smooth turning vs snap turning, and teleport aids.
