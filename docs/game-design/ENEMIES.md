# Enemy Archetypes & AI Behavior: VORIXA

Hostile entities operate under reactive utility-based AI rather than rigid state-locked scripts.

## 1. Core Enemy Archetypes

| Archetype | Class | Behavior Pattern | Threat Signature |
| --------- | ----- | ---------------- | ---------------- |
| **Scarab Drone** | Swarm / Melee | Skitters in groups of 4–8, leaps when within 6m, explodes on death with acid splash | High numbers, low HP |
| **Sentinel Prowler** | Stalker / Skirmisher | Cloaks when moving, circles player perimeter, fires twin plasma darts before repositioning | High agility, ambush specialist |
| **Aegis Colossus** | Heavy / Suppressor | Slow advance with directional shield, fires homing artillery mortars, susceptible to rear vents | Massive armor, area denial |
| **Phase Phantom** | Aerial / Disruptor | Teleports between aerial vantage points, channels energy beams that drain player stamina | Vertical threat, requires hit-scan |

## 2. Squad Coordination
* **Flanking Tokens**: Enemies request attack tokens from a squad arbiter so no more than 2 high-damage strikes occur simultaneously.
* **Morale / Suppression**: Heavy kinetic fire forces lighter automatons into temporary defensive retreats behind rocks or shields.
