# In-Game Economy: VORIXA

## Resource Matrix

| Resource | Origin | Primary Sink |
| -------- | ------ | ------------ |
| **Resonance Shards** | Defeated Guardians, Mineral nodes | Upgrading weapon tier in Waypoint Archive |
| **Volatile Isotopes** | High-entropy anomaly sites | Crafting consumable jump thrusters & nanites |
| **Ancient Data Slates** | Ruined Monolith archives | Unlocking permanent passive perk matrix |

Economy sinks are balanced to require continuous exploration across diverse biomes rather than grinding a single repetitive area.
