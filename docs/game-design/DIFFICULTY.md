# Difficulty Calibration: VORIXA

## Adaptive Difficulty System

1. **Player Skill Profiling**: Tracks player performance over sliding 60-second windows (damage taken vs dealt, precision accuracy, velocity maintained).
2. **Pacing Valves**: If player health falls below 20%, enemy aggression drops by 30% for 10 seconds to allow recovery, unless in a Boss Encounter.
3. **Opt-In Hardcore Mutators**: Hardcore players can attune "Torment Cores" to boost reward drop rates by up to 400% in exchange for zero forgiveness windows and permadeath for that run.
