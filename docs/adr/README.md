## ADR Template Standard
Every ADR must document:
1. **Title & Status** (Proposed, Accepted, Deprecated, Superseded)
2. **Context** (The problem, requirements, constraints)
3. **Decision Drivers**
4. **Considered Options**
5. **Decision & Justification**
6. **Consequences** (Positive and negative tradeoffs)
