# Typography System: VORIXA

## Font Families
* **Display / Headings**: `Outfit, system-ui, -apple-system, sans-serif` (weight 600–800)
* **HUD Telemetry / Readouts**: `JetBrains Mono, ui-monospace, monospace` (weight 500)
* **Body / Story**: `Inter, system-ui, sans-serif` (weight 400)

## Hierarchy
* `Display Large`: 32px / line-height 1.2 (Sector names, monolith discoveries)
* `HUD Metric`: 16px / line-height 1.0 (FPS counter, shield percentage, velocity)
* `Body`: 14px / line-height 1.5 (Codex entries, tutorial cues)
* `Micro Badge`: 11px / line-height 1.2 (Device tier badge, WebGPU indicator)
