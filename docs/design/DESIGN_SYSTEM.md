# Design System & UI Principles: VORIXA

The presentation layer uses clean, glassmorphic HUD surfaces with high contrast and sub-millisecond layout responsiveness.

## Design Tokens
* **Base Background**: `#08090d` with $40\%$ backdrop blur on overlays.
* **Border Highlights**: `1px solid rgba(0, 240, 255, 0.25)` with neon corner notches.
* **Typography Stack**: Monospace numerals (`JetBrains Mono`, `Fira Code`) paired with geometric sans (`Inter`, `Outfit`).
* **Motion**: Quick micro-transitions ($120\text{ms}$) with snappy `cubic-bezier(0.16, 1, 0.3, 1)` easing.
